# 零成本搭建 AI 工具导航：Cloudflare Workers + D1 实战指南

这是一个完全免费、无需服务器、自带访问统计、支持中英双语、拥有漂亮毛玻璃特效的 AI 工具导航网站。

它不需要你购买阿里云/腾讯云的服务器，也不需要配置复杂的数据库环境，全部依托于 Cloudflare 的边缘计算网络（Workers）和云数据库（D1）运行。

## 1. 核心设计思路（为什么这么写？）

很多小白做网站，一上来就搞 Vue/React + Node.js + MySQL，不仅学习成本高，而且还要花钱买服务器。我们的思路是 **“极简与白嫖”**：

*   **前端无框架（Vanilla JS）**：不依赖 React/Vue，用原生 JS 渲染页面。代码全在一个文件里，加载速度极快，且不需要 npm build 编译。
*   **服务端渲染（SSR）**：把 HTML 骨架和数据在 Worker 服务端直接拼装好发给浏览器，对 SEO（搜索引擎收录）非常友好。
*   **数据与逻辑分离**：AI 工具的列表（名称、网址、描述）直接写成 JSON 数组放在代码里，修改起来像改 Excel 一样简单；而“访问统计”这种需要动态变化的数据，则存入 Cloudflare D1（免费的 SQLite 云数据库）。
*   **防呆与兜底设计**：考虑到网络环境（如 Google 图标服务被墙），代码里做了“首字母渐变图标”兜底；考虑到新手容易改错代码，加了全局 `try...catch`，就算 JS 报错也会把错误直接显示在网页上，而不是白屏。

## 2. 完整安装与部署方法（小白保姆级）

### 准备工作
1. 注册一个 [Cloudflare](https://dash.cloudflare.com/) 账号。
2. 在电脑上安装 [Node.js](https://nodejs.org/)（建议 18.x 或以上版本）。

### 第一步：初始化项目
在电脑上新建一个文件夹（比如叫 `ai-nav`），在里面新建两个文件：
*   `wrangler.toml`（Cloudflare 的配置文件）
*   `src` 文件夹，在里面新建 `index.js`（我们的核心代码）

### 第二步：配置 wrangler.toml
打开 `wrangler.toml`，填入以下基础配置：

```toml
name = "ai-nav"
main = "src/index.js"
compatibility_date = "2024-01-01"
```

### 第三步：创建云数据库 (D1) 并建表
打开电脑终端（命令行），依次执行以下命令：

```bash
npx wrangler d1 create ai-nav-db
```

> ⚠️ **注意**：执行完后，终端会输出一段包含 `database_id = "xxxx..."` 的代码，把这段代码复制，粘贴到你的 `wrangler.toml` 文件最下方。

接着，给数据库建表（创建存放统计数据的抽屉）：

```bash
npx wrangler d1 execute ai-nav-db --remote --command "CREATE TABLE IF NOT EXISTS visits (id INTEGER PRIMARY KEY, count INTEGER DEFAULT 0);"
```

### 第四步：填入代码并部署
将你的代码完整复制，粘贴到 `src/index.js` 中并保存。最后在终端执行部署命令：

```bash
npx wrangler deploy
```

看到 `Published ai-nav` 的提示，就说明你的网站已经上线啦！终端会给你一个 `https://ai-nav.xxx.workers.dev` 的网址，直接访问即可。

## 3. 踩坑血泪史（小白必看避坑指南）

### 💣 坑 1：统计胶囊死活不出来，数据库连不上
*   **现象**：网站能打开，但搜索框下面的“今日访问”等统计胶囊不显示。
*   **原因**：如果你在 Cloudflare 网页控制台里手动绑定了 D1 数据库，但之后又用命令行 `npx wrangler deploy` 部署了代码——命令行会以本地的 `wrangler.toml` 为准，把网页上的绑定给覆盖（清除）掉了！
*   **解决**：永远把绑定配置写在 `wrangler.toml` 里。并且，变量名必须严格大写 `DB`。

### 💣 坑 2：页面白屏，或者只有搜索框没有卡片
*   **现象**：网页骨架出来了，但 AI 工具列表空空如也。
*   **原因**：前端 JS 报错了，导致渲染中断。通常是因为复制代码时，不小心漏了括号，或者 JSON 数据里包含了 `<`、`>` 等符号破坏了 HTML 结构。
*   **解决**：代码里使用了 `.replace(/</g, "\\u003c")` 来转义。如果出错，网页中间会直接显示红色的 `⚠️ 页面脚本出错`，让你一眼看出是哪行代码写错了。

### 💣 坑 3：CSS 样式突然乱掉 / 毛玻璃失效
*   **现象**：卡片没有毛玻璃效果，或者排版挤在一起。
*   **原因**：在修改 CSS 时，多打了一个 `}`，或者少写了一个分号 `;`。
*   **解决**：推荐使用 VS Code 等代码编辑器，它会自动帮你高亮匹配的括号。按 F12 打开开发者工具，查看 CSS 面板是否有红色波浪线报错。

### 💣 坑 4：工具图标加载不出来（变成白纸）
*   **现象**：卡片左侧的图标空白。
*   **原因**：代码默认使用了 Google 的 Favicon 抓取服务（`t1.gstatic.com`），在国内经常访问不到。
*   **解决**：代码里做了“双保险”。底层是一个带渐变色和首字母的 `DIV`，上面覆盖图片。如果图片加载失败（`onerror="this.remove()"`），图片会被移除，完美露出底下的首字母渐变图标。

## 4. 后续进阶玩法

1.  **绑定自己的域名**：在 Cloudflare 控制台 -> Workers -> 你的 Worker -> Settings -> Domains & Routes，添加你在 Cloudflare 托管的域名即可。
2.  **添加新的 AI 工具**：打开 `src/index.js`，找到 `const TOOLS = [...]` 数组，照着格式加一行 JSON，重新 `deploy` 即可。
3.  **增加访问密码**：可以在 Worker 拦截器里加一段逻辑，检查请求头或 Cookie 里的密码，不对则返回 403，把它变成你的私人书签库。

> **结语**：从看着一堆报错发呆，到看着毛玻璃特效和统计数据在页面上丝滑跳动，这个过程就是编程最大的乐趣。不要怕报错，每一个红色的 Error 都是在教你理解底层的运行逻辑！
